# ピアノ演奏モニタ（MIDI）

電子ピアノをつなぎ、**弾いた音を鍵盤に光らせ、いま鳴っている音を楽譜にし、演奏を録ってあとから眺める**ためのツールです。ブラウザだけで動きます。判定も採点もしません。自分の演奏を見るだけの道具です。

**→ 公開版　https://ku-ron.github.io/piano_monitor/**
**→ 鍵盤だけ（配信用）　https://ku-ron.github.io/piano_monitor/keys.html**

姉妹プロジェクト [コード弾き練習 MIDI Ver.](https://github.com/ku-ron/chord_practice_midi)（[公開版](https://ku-ron.github.io/chord_practice_midi/)）が「弾くべきコードを出して、ちゃんと押せたか見る」のに対し、こちらは**弾いたものをそのまま映す**側です。

## 画面

上から順に、**調（五度圏と調号の候補）／楽譜・コード名・音の使われ方／ベロシティと鍵盤／ペダル**、そのあとに録音とふりかえりが並びます。

上の2段は、iPad mini の縦（744×1133）でそれぞれ1行に収まり、かつ**鍵盤までが1画面に入る**寸法にしてあります（3段目の下端が上から1000pxほど）。620pxより狭い画面では素直に折り返します。

### 1. 鍵盤（88鍵）とベロシティ

- **青** … いま指で押している音。強く弾くほど濃くなります
- **黄** … 指は離したが、ペダルでまだ鳴っている音

鍵盤の**真上に、鳴っている音のベロシティが棒グラフ**で出ます。鍵の位置にそのまま合わせてあるので、どの音をどれだけの強さで弾いたかが一目で分かります。ペダルで残っている音も（黄色で）出ます。

同じ音を鳴っているうちに弾き直したときは、**大きいほうのベロシティが残ります**。強く打った弦がまだ響いているのに、弱く叩き直したからといって弱い音になるわけではないためです。右上に、そのとき鳴っている中での最大値も出します。

鍵盤はクリック／タップでも反応します。ピアノが手元になくても、楽譜や音名の出かたを試せます（音は出ません）。

### 2. 楽譜（大譜表）

いま鳴っている音を全音符で置きます。**時間の情報は持ちません**。和音の構成が見えればよい、という割り切りです。ペダルで残っている音は灰色の符頭で出ます。

中央ハ（C4）以上を高音部、それより下を低音部に振り分けます。加線は必要なだけ引きます。

**枠の高さは固定**で、どの調でも 88鍵の両端（A0・C8）が最初から収まる高さにしてあります。音域に合わせて伸び縮みすると、弾いている最中に譜面が動いて読みにくいためです。ふだんは上下に余白が空きますが、それでよしとしています。

### 3. 調の選択（五度圏）

**調を選ばないと音名が決まりません。** 同じ黒鍵でも F♯ と G♭ は別の音名で、どちらを書くかは調で決まります。長調15・短調15から選びます。

五度圏の輪をタップして選びます。指で押せるよう、いちばん上の段に大きく置いてあります。**外側が長調、内側がその平行調（短調）**です。真ん中に、いま選んでいる調の調号が出ます。

同じ位置に2通りの綴りがある3か所（B と C♭ ／ F♯ と G♭ ／ D♭ と C♯）は、**♯♭の少ないほうを輪の中に置き、多いほうを輪の外と内へはみ出させています**。輪だけを見れば、いつも簡単なほうの綴りが並びます。

綴りは五度圏の上で「その調の中心にいちばん近い書き方」を選びます。結果として

- E♭メジャーなら 66番の音は **G♭**（F♯ ではない）
- Aマイナーなら 68番の音は **G♯**（A♭ ではない。導音なので）
- E♭メジャーの 59番は **B♮**（C♭ にはしない）

のようになります。調号にある変化記号は音符側では省き、調号と違うときだけ ♯♭♮ を付けます。同じ音名（例：D♮ と D♭）が同時に鳴っているときは、紛れないよう両方に記号を出します。

### 4. 調号の候補（弾いた音からの推定）

五度圏の右に、**いま弾いている音がどの調号に合うか**を上位5つ並べます。左から **調号・長調名・短調名・一致度のグラフ**の順です。名前のボタンを押すと、その調に切り替わります。ボタンの幅は文字数によらず固定なので、候補が入れ替わっても位置がずれません。

**同率一位が複数あるときは、そのすべてを明るく**します（1音しか弾いていないときなど、決められない場面では並んで光ります）。

**分かるのは調号までです。** 長調とその平行短調（C と Am など）は使う7音がまったく同じなので、音の種類だけでは区別できません。そこは弾いている本人が選ぶ前提にしています。

やっていることは単純で、直前 N 音のピッチクラスを数え、**五度線の上で「7音ぶんの窓」がいちばんよく合う位置**を探しているだけです。窓から外れた音は、外れ具合に応じて減点します（1つ外は軽い減点、遠いほど重い）。実際に音階を流し込んで確かめた結果:

| 弾いたもの | 出た候補 |
|---|---|
| Cメジャー音階 | 調号なし（1.00） |
| E♭メジャー音階 | ♭3（1.00） |
| Aナチュラル短音階 | 調号なし（1.00）← Cメジャーと同じ調号なので正解 |
| Aハーモニック短音階 | 調号なし（0.80）← G♯ のぶん減点される |
| F♯メジャー音階 | ♯6（1.00。＝♭6 とも表示） |
| 半音階 | どれも 0.53 前後で横並び（決められない、が正しい） |

### 5. 音の使われ方（ピッチクラスの割合）

12のピッチクラスそれぞれを何回弾いたかを、**いちばん多い音を1とした割合**の棒グラフで出します。いま選んでいる調に入っている音は青、外れている音は灰色です。棒の上の数字は実際の回数です。

**「直前 N 音から集計」のつまみ**で、さかのぼる音数を 8〜256 の間で変えられます。この値は上の調号の候補にも効きます。このグラフの上にある**「集計をリセット」**を押すと、それまでに弾いた音を全部忘れます（調号の候補もいっしょに白紙に戻ります）。曲を変えるときに使ってください。

- **少なくする**（8〜16）… 転調にすぐ追いつきますが、ふらつきます
- **多くする**（96〜256）… 安定しますが、転調に気づくのが遅れます

実際に「Cメジャー音階のあとAメジャー音階」を流すと、窓8では ♯3（A メジャー）を出し、窓48では ♯1 あたりで迷ったままになります。どのくらいが弾きやすいかは曲と好みによるので、つまみで探してみてください。

### 6. コード名

構成音がぴったり一致したときだけ出します。最低音が根音でなければ `C / E` のように分数で出します。**当てずっぽうの名前は出しません** — ペダルで音が溜まっているときはたいてい空欄になります。

### 7. ペダル

鍵盤のすぐ下に、踏み込みの深さが横棒で出ます。棒の途中に入っている縦線が「踏んでいる」と見なす境目（64）です。ハーフペダルもそのまま見えます。

- **CC64（ダンパー）** … 64以上で「踏んでいる」と見なし、離鍵しても音を鳴り続けている扱いにします
- **CC66（ソステヌート）** … 踏んだ瞬間に押していた音だけを保持します
- **CC67（ソフト）** … 深さの表示のみ

ソステヌートとソフトは、その機種が実際に送ってきたときだけ表示に出ます。

「ペダルで音を保持」のチェックを外すと、指で押している音だけを見ます。

## 録音

「● 録音開始」から「■ 停止」までの MIDI を丸ごと記録します。録るだけの区画で、下の「ふりかえり」とは分けてあります。

## ふりかえり

録音を選ぶと、3つのグラフが出ます。

| グラフ | 中身 |
|---|---|
| ダイナミクス | 打鍵ごとのベロシティ（点）と、1秒窓の移動平均（線）。1.5秒以上あいたら線を切ります |
| ペダルの深さ | CC64/66/67 の値そのものを階段状に。破線は「踏んでいる」境目（64） |
| 同時に鳴っている音の数 | 押している数と、ペダル込みで鳴っている数。ペダルでどれだけ音を溜めているかが見えます |

- 横にドラッグすると**その範囲だけ拡大**します。ダブルクリックか「全体」で戻ります
- カーソルを動かすと3つのグラフに縦線が揃い、その時刻の値が出ます
- 上には演奏時間・音数・ベロシティの平均と最大最小・最大同時発音数・ペダルを踏んでいた割合を出します

### 再生

録ったものをそのまま鳴らせます。出力先は2つから選べます。

| 出力先 | どうなるか |
|---|---|
| **〇〇 に送る**（MIDI出力） | 電子ピアノに MIDI を送り返し、**ピアノ自身に弾かせます**。自動演奏機能と同じで、音はいちばん実物に近くなります |
| **内蔵音（ピアノ音源）** | ブラウザの中で鳴らします。ピアノがつながっていないときに使います |

- 再生中は**鍵盤・ベロシティ・楽譜が当時のとおりに動きます**。グラフには再生位置の線（黄）が走ります
- **グラフをクリックすると、そこが再生開始位置になります。** 気になった箇所だけ何度も聴き直せます
- ペダルも一緒に再生します。内蔵音のほうもダンパーを踏んでいる間は音を残します
- 停止すると、鳴りっぱなしを防ぐため全鍵のノートオフを送ります

### 内蔵音について

内蔵音は**実際のピアノを録音したもの**（[Salamander Grand Piano](https://github.com/sfzinstruments/SalamanderGrandPiano)。Alexander Holm 氏がヤマハ C5 を収録、CC-BY 3.0）を鳴らしています。3半音おきに30音、**合計約1.9MB**を、内蔵音を選んだときにだけ取りに行きます。同梱していないのは、HTML 1枚という形を崩したくないためです。

- 一度読み込めば **Cache API に残るので、次からは通信なしで鳴ります**（ただし `file://` で直接開いた場合はページごとに消えるため毎回読み直します。サーバ／GitHub Pages 経由なら残ります）
- 読み込みに失敗したときは、**その場で合成した音**に自動で切り替わります（倍音を3群に分けて別々に減衰させ、弦2本のうなり・打鍵の雑音・残響を足したもの）。本物には及びませんが、鳴らないよりはましという位置づけです
- 強さは、音量と明るさ（ローパス）の両方で表しています。録音は1段階の強さしか無いためです
- **F6 より上にはダンパーが無い**ので、鍵を離しても鳴り続けます

### 名前と削除

録音の名前は最初は日時（例 `8/14 01:20`）ですが、**「名前」ボタンから好きに変えられます**。曲名やメモを入れておくと後で探しやすくなります。録音日時はグラフの上に別に出るので、名前を変えても分からなくなりません。書き出すファイル名にもこの名前が使われます。

**「削除」を押すと確認の窓が出ます。** ブラウザ標準の確認ダイアログ（`confirm`）は、表示してくれないブラウザ（MIDIWeb Browser など WKWebView 系）があり、その場合「押しても何も起きない」状態になるため、確認の窓は自前で描いています。

### 書き出し

- **.mid** … 標準MIDIファイル（format 0、♩=120 換算）。DAWや採譜ソフトで開けます
- **.json** … 記録したイベントをそのまま

録音は端末のブラウザ内（localStorage）に残るので、次に開いたときも一覧に出ます。ただし容量には限りがあり、入りきらない分は古いものから消えます。**残したい演奏は .mid で保存してください。**

## 鍵盤だけのページ（配信用）

**→ https://ku-ron.github.io/piano_monitor/keys.html**

MIDIの接続と、**鍵盤・ベロシティ・ペダルだけ**を切り出した別ページ（`keys.html`）です。配信ソフト（OBSなど）のブラウザソースに入れて、手元の動きを画面に重ねるために作りました。PCのブラウザ向けです。

- 鍵盤は窓の幅いっぱいに広がり、窓の形に合わせて縮みます
- **一度MIDIを許可すれば、次からは開いただけでつながります**（配信ソフトは画面をクリックしにくいため）
- 上の操作バーは、**つながったあとマウスが止まると消えます**。動かすとまた出ます

### 流れる表示（音ゲー風）

「流れる表示」を入れると、**弾いた音が鍵盤から上へ流れていきます**。押している間ずっと帯が伸び、離すと下端も動き出して上へ抜けていきます。

- **指で押している間は青、ペダルだけで残っている間は黄**です。色が変わるところで帯を区切っているので、どこからペダルで保っているかが見えます
- 同じ音を弾き直すと、そこで帯が切れます
- **速さ**は「上まで流れきる時間」で決めます（1.0〜8.0秒）。窓の大きさが変わっても見え方が変わらないよう、画面の高さを基準にしています
- 帯の横位置と幅は鍵にぴったり合わせてあります（鍵盤が余白付きで表示されても、ずれないように毎回計算しています）

**「ベロシティ」を切ると、帯が鍵からそのまま出てくる**見た目になります（ベロシティの棒を出したままだと、その棒のぶん上から出てくることになります）。

### URLで見た目を決められる

配信ソフトからはクリックしづらいので、URLの後ろに付けて指定できます。

| 付けるもの | 何が起きるか |
|---|---|
| `?clear=1` | **背景を透明に**する（映像の上に重ねる用）。文字と線には黒い縁取りが付くので、明るい映像の上でも読めます |
| `?bar=0` | 上の操作バーを最初から出さない |
| `?flow=1` | 流れる表示を入れる |
| `?sec=3` | 流れる速さ（上まで流れきる秒数、1〜8） |
| `?vel=0` | ベロシティの棒を出さない（鍵盤が大きく映る） |
| `?pedal=0` | ペダルの棒を出さない |

組み合わせは `keys.html?flow=1&vel=0&clear=1&bar=0` のように `&` でつなぎます。画面のチェックボックスやつまみでも切り替えられ、次回も覚えています（URLで指定したほうが優先です）。

### OBSでの使い方

1. ソースに「ブラウザ」を追加し、URLに `https://ku-ron.github.io/piano_monitor/keys.html?clear=1&bar=0` を入れます
2. 幅は 1920、高さは 360 くらい（ベロシティを出さないなら 200 くらい）が目安です
3. 初回だけ、ソースを右クリック →「操作」でページを開き、MIDIの接続を許可してください

**注意：** 配信ソフトの内蔵ブラウザ（OBSはCEF）で Web MIDI が使えるかは環境によります。動かないときは、**Chromeでこのページを開いてウィンドウキャプチャする**方法が確実です（その場合も `?clear=0&bar=0` で見た目は整います）。手元にOBSが無いため、この経路は未検証です。

## つなぎ方と動作環境

```
電子ピアノ ──(Bluetooth MIDI または USB)──→ 端末     モニタ用のデータ
電子ピアノ ──(ヘッドホン・内蔵スピーカー)──→ 耳      弾いた音
```

**音は電子ピアノ自身に鳴らさせてください。** このアプリは音を出しません。

| 環境 | どうするか |
|---|---|
| Mac / Windows | **Chrome、Edge、Firefox 108+** で https://ku-ron.github.io/piano_monitor/ を開くだけ |
| iPad / iPhone | **[MIDIWeb Browser](https://apps.apple.com/us/app/midiweb-browser/id6757226617)**（無料）で同じURLを開く。Bluetooth MIDI のペアリングもこのアプリの中から |
| Mac版Safari | **MIDIは動きません**（Web MIDI API 未対応） |
| Android | Chrome / Samsung Internet なら動くはず（未検証） |

Safari が Web MIDI に対応していない件は姉妹プロジェクトの README に詳しく書いてあります。iOS はすべてのブラウザが WebKit なので、iPad版 Chrome を入れても同じです。

Bluetooth **オーディオ**は使わないでください（MIDI とは別物で、150〜250ms 遅れます）。

## わりきったところ

- **リズムは書きません。** 楽譜は「いま鳴っている音」だけで、音価も小節も拍もありません
- コード名は**完全一致のときだけ**。テンションが中途半端に混ざると空欄になります
- 再生速度は変えられません（等倍のみ）
- **チャンネル10は無視します。** 一部の機種がメトロノームやドラムをここに流すためです

## ファイル

`index.html`（本体）と `keys.html`（鍵盤だけの配信用）の2枚だけです。ビルドも依存もありません。GitHub Pages にそのまま置いてあります（[公開版](https://ku-ron.github.io/piano_monitor/)）。手元にダウンロードしてダブルクリックしても動きます。

`keys.html` は本体から、MIDIの受け取りと発音の考え方・鍵盤の描画だけを持ってきた独立したページです（読み込みを1ファイルで完結させたいので、共通化せずに写しています）。

主な部品は上から順に、音名の綴り（五度圏）、調号の推定、MIDI受信と発音モデル、88鍵とベロシティの描画、大譜表の描画、コード判定、録音、グラフ、再生、SMF書き出し、です。

## 使わせてもらっているもの

| | |
|---|---|
| **[Bravura](https://github.com/steinbergmedia/bravura)**（SIL Open Font License 1.1） | 音部記号・変化記号・全音符・中括弧の字形。SMuFL標準の楽譜用フォントから**必要な9文字だけ**を SVG パスとして取り出して埋め込んでいます。フォントファイル自体は同梱していません（環境に楽譜用フォントがあるとは限らないため） |
| **[Salamander Grand Piano](https://github.com/sfzinstruments/SalamanderGrandPiano)**（Alexander Holm、CC-BY 3.0） | 内蔵音の音源。[Tone.js の配布先](https://tonejs.github.io/audio/salamander/)から実行時に読み込みます |

どちらも自由に使える条件で公開されているものです。ライブラリは読み込んでいません（Tone.js 本体も使っていません。音のファイルだけを取得しています）。

デバッグ用に `window.__inject([0x90,60,80])` で実機と同じ経路にMIDIを流し込めます。
